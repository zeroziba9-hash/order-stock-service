# 상품 탐색 화면과 상세 정보

상품 목록의 소개·필터 여백을 줄이고, 검색창과 정렬창의 비율을 조정했습니다. 넓은 화면에서는 상품을 3열로, 작은 화면에서는 1열로 배치합니다.
모바일에서는 상단 장식 이미지를 생략해 상품으로 더 빨리 이동합니다. 장바구니 버튼을 주 동작으로 강조하고 보조 글씨의 대비·크기를 보완했습니다.
실제 상품 수와 무관했던 하단 장식 숫자는 제거했습니다.

상품 이미지·이름은 `/#product/{id}`로 연결합니다. 상세 주소로 바로 접속하거나 새로고침해도 서버에서 해당 상품을 다시 조회합니다.
현재 이름·가격·재고, 수량별 예상 금액, 등록된 설명·규격, 주문 안내를 표시합니다.
일러스트는 코드로 그린 표현이며 상품 번호에 따라 색조를 구분합니다. 실제 색상·재질·용량을 증명하는 사진이 아닙니다.
상세 화면에서도 일러스트임을 안내하며, 확인하지 않은 상품 정보는 생성하지 않습니다. 설명·규격이 비어 있으면 해당 구역을 숨깁니다.

## 상세 화면의 동작

- `GET /products/{id}`는 판매 중인 상품의 현재 정보와 설명·규격을 익명 조회합니다. 품절 상품도 볼 수 있지만 판매 중지·없는 상품은 404입니다.
- 수량을 골라 장바구니에 담거나 바로 주문할 수 있습니다. 로그인 안내 후에도 선택한 수량을 유지합니다.
- 바로 주문도 기존 [가격 확인 주문](checkout-and-cart.md)을 거칩니다. 상세 화면에 표시된 재고를 예약하지 않습니다.
- 조회 실패는 오류·다시 불러오기 버튼으로 표시합니다. 상품을 바꾼 뒤 늦게 도착한 이전 응답은 무시합니다.
- 검색 결과가 없으면 검색 조건 안내와 전체 상품으로 돌아가는 동작을 제공합니다.

## 설명·규격 관리

관리자는 상품 관리 화면에서 상품을 선택하고 별도의 **상품 설명과 규격** 양식에 입력합니다.
설명은 최대 2,000자, 규격은 최대 1,000자이며, 일반 텍스트와 줄바꿈을 보존합니다. HTML은 화면에서 글자로 표시합니다.

`GET /admin/products/{id}/content`는 `{description, specification, revision}`을 반환합니다.
`PUT`에 세 필드를 모두 보내고, 빈 문자열로 내용을 지울 수 있습니다.
직전 수정 버전을 비교해 다른 접속의 변경을 `409 CONTENT_CHANGED`로 보호합니다. 이름·가격·판매 상태의 수정 버전과 독립적이며 설명 수정으로 확인된 주문 가격이 바뀌지 않습니다.
변경이 없는 저장은 새 버전·이력을 만들지 않습니다.

설명·규격과 수정 전후 값·관리자 ID·UTC 시각을 한 트랜잭션에 기록합니다.
`GET /admin/products/{id}/content/changes?beforeId=...`는 최대 20건씩 반환합니다. 화면에서 이전 변경을 더 조회할 수 있습니다.
이력 저장 실패는 설명과 버전 변경도 함께 롤백합니다. 권한은 요청 때마다 현재 DB의 관리자 역할로 확인합니다.

V19는 `product_content`, `product_content_changes`를 추가합니다. 과거 설명을 추측해 채우거나 이전 변경 이력을 만들지 않습니다.
기존 상품·주문·재고·계정·저장 장바구니·가격 확인 데이터는 변경하지 않습니다.

등록 이미지·미리보기·삭제·이미지 오류 fallback은 [상품 이미지 관리](product-images-and-order-recovery.md)에 정리했습니다. 등록 이미지가 있으면 기본 일러스트 대신 표시합니다.

실제 응답 필드는 [API 가이드](api-documentation.md), 데스크톱·모바일 흐름은 [브라우저 검증](browser-tests.md)에서 확인합니다.
